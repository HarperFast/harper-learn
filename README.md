## 📖 About This Repository

This repository serves as the companion resource for the Harper Learn video series. Each week's directory contains:

- **README.md** — Episode summary, talk track, timestamps, and links to watch on various platforms
- **Code samples** — Practical examples demonstrated in the video (when applicable)

The goal is to create a living learning resource that grows alongside the series, making it easy to reference past content and track the learning journey.
