# Guest Episode: Dawson Toth on Fabric

**Duration:** ~15-20 minutes • **Difficulty:** Intermediate to Advanced • **Format:** Interview/Demo

---

## Overview

Join Dawson Toth, creator of Fabric, for an exploration of how Fabric extends Harper's capabilities for building distributed, edge-native applications. Learn about Fabric's architecture, use cases, and how it complements Harper's platform to enable new patterns for edge computing and distributed systems.

**What we'll cover:**
- What is Fabric and why it exists
- Fabric's architecture and design philosophy
- Integration with Harper
- Edge computing patterns with Fabric
- Real-world use cases and deployments
- Building distributed applications with Fabric + Harper
