# Harper Plugin Template & Testing Guide

**Duration:** ~10 minutes • **Difficulty:** Intermediate

---

## Overview

Learn how to use Harper's official plugin template to quickly scaffold new plugins with best practices built-in. This episode covers the template structure, configuration options, and comprehensive testing strategies for Harper plugins including unit tests, integration tests, and end-to-end testing.

**What we'll build:**
- A new plugin from the official template
- Complete test suite (unit, integration, E2E)
- CI/CD pipeline configuration
- Local development workflow

By the end, you'll have a production-ready plugin development workflow with automated testing.
