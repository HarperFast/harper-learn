# Guest Episode: Ethan Arrowood on Harper's Plugin System

**Duration:** ~15-20 minutes • **Difficulty:** Intermediate to Advanced • **Format:** Interview/Demo

---

## Overview

Join Ethan Arrowood, the architect behind Harper's extensible plugin system, for an in-depth conversation about the design, implementation, and future of Harper's plugin architecture. Learn the "why" behind key design decisions, explore advanced patterns, and get a peek at what's coming next.

**What we'll cover:**
- The evolution of Harper's plugin system
- Key architectural decisions and trade-offs
- Design patterns for extensibility
- Performance considerations
- Future roadmap and upcoming features
- Q&A with the architect
