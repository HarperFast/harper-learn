## Overview

This week we bring IoT into the mix by leveraging Harper's built-in MQTT functionality with one of the Vue.js apps from Week 3. You'll learn how to use Harper's native MQTT support to send messages from your web application to control a real device, bridging the gap between web development and hardware. By the end, you'll have a working example of browser-to-device communication without any additional libraries.
